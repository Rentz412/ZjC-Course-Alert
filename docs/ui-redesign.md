# 华珠课表 · 画布风格原生实现

本轮以用户认可的 Vetta 画布为视觉依据，移除 Miuix UI、Preference、Core、Icons 依赖，使用 Compose Foundation 自定义控件。没有改用 Material 默认视觉组件。现有教务协议、Room 缓存、加密账户、提醒调度、日历导出和应用更新继续工作。

## 首页与统一视觉

- 移除首页「上一周」「下一周」「回到今天」按钮；通过本周日期条选择日期，点「今天」回到当天。
- 标题栏、底栏、文字按钮、输入框、开关、底部抽屉和提醒时间选项均由本地控件定义尺寸、字号、颜色与间距。
- 提醒时间采用一行五等分；输入框统一为 54 dp 基准高度，并允许大字体需要时自然增长。
- 引入画布同款 DM Sans 和 Instrument Serif 字体；中文按系统字体回退。线性图标采用 Lucide 风格几何，统一描边。
- 保留浅色、深色主题和上一轮的对称子页面动画：右侧滑入、向右滑出，后半段淡出；普通返回和手势返回一致，取消手势恢复原页。
- 部分已有页面通过本地导入别名兼容旧的主题、图标引用；这些别名均指向本项目自定义实现，不引入 Miuix 组件或样式。

## 课表长文本修复

原问题是课块高度固定，而课程名、教室与教师分别占用的实际高度相加超过容器，导致底部字符直接被裁掉。

新的布局先按实际列宽、字体与系统字号缩放测量全部文本，再计算每门课需要的高度。所有日期共用同一组节次行高，同一节次的长内容会让对应行一起增高，课块仍按真实节次边界定位。

- 课程名、教室、教师均完整换行，不用省略号隐藏信息，也不缩小字号。
- 跨节课程、重叠课程共用一致的行高约束，不改变原有课程周次或作息语义。
- 窄屏、重叠课程与大字体下有最小列宽保障；不足时横向滚动，头部和课块同步。
- 较长内容允许纵向滚动。一个屏幕不能容纳整周内容时，完整信息仍保留在网格内。
