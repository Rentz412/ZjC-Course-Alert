# 桌面小部件 · 日程手账

## 设计与操作

本轮实现一个可切换日期的单天日程小部件，沿用 App 的纸白底、墨绿配色、DM Sans / Instrument Serif 字体、浅色卡片和原生深色主题。背景完全不透明，避免壁纸干扰文字阅读。

- 默认建议 4 × 4，支持调整宽高；Android 12 以下由桌面根据最小尺寸分配网格。
- 上方显示品牌、日期、星期、教学周和当天课程数；点标题打开 App。
- 底部固定「前一天 / 今天 / 后一天」。点击今天清除固定日期，恢复跟随当天；浏览其他日期后保持该日期。
- 可以放置多个小部件，各自保存浏览日期，互不覆盖。
- 课程列表支持滚动，课程名、教室、教师完整换行，显示开始/结束时间和节次。
- 今天的课次显示待上课、进行中、已结束；浏览其他日期不套用今天的时钟状态。正在上的课程用浅绿底突出。
- 右上角刷新按钮重新读取本地课表并更新状态，不会发起教务登录或同步。
- 「今日休息」仅标记当天，不隐藏课程；无缓存、无课、学期外及读取失败有不同提示。
- 保留原 provider 组件名，使已有桌面小部件可以升级。旧实例尺寸过矮时显示拉高提示；可以长按调整高度，也可以移除旧实例后重新添加。

## 添加入口修复

进入「我的 → 桌面小部件」立即显示预览和添加引导。

支持直接添加的桌面会显示「请求添加到桌面」按钮。请求返回 false 或抛出异常时给出明确提示；返回 true 时只提示已发送请求，必须由用户在系统弹窗确认，不把请求接受误报为添加成功。

界面始终保留手动添加步骤和「回到桌面」按钮。部分厂商桌面即便宣称支持直接添加，也可能不显示弹窗，可长按桌面空白处，在小部件列表中找到「华珠课表 · 日程手账」。

预览明确使用示例课程。真正添加后读取当前所选学期的本地数据库，不将示例课程写入用户数据。

## 兼容性与更新

- 基础配置与 Android 12+ 配置都使用原生 RemoteViews 初始布局，移除了旧 Glance loading 引用和 Glance 运行时依赖。
- 课程列表使用桌面支持的 ListView。ScrollView 不属于 RemoteViews 允许的控件，不能用于该布局。
- Android 12+ 使用 RemoteCollectionItems；Android 8–11 使用受 BIND_REMOTEVIEWS 权限保护的服务适配器。
- 日期按钮的 PendingIntent 按实例和动作区分；广播使用 goAsync，在本地读取和更新结束后释放，并串行处理日期变更。
- 成功同步、切换学期、手动校准学期起点或改变休息状态时刷新小部件。
- 系统定期更新请求为 30 分钟，实际执行会受到桌面与系统后台策略影响；并非每分钟实时刷新。页脚显示更新时间，可以手动刷新。
- 「跟随今天」在收到刷新或系统日期/时间变化广播时重新计算日期，不承诺后台精确零点刷新。
